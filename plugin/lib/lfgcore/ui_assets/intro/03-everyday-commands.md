# Everyday commands

## In Claude Code

| Command | What it does |
| --- | --- |
| `/lfg:lfg <request>` | The whole pipeline for one change |
| `/lfg:fix <bug>` | Reproduce, fix and prove a bug |
| `/lfg:explain <question>` | How does this part of the code work? |
| `/lfg:why <file:lines>` | Why does this code look like this? |
| `/lfg:impact <symbol>` | What could this change break? |
| `/lfg:expert` | A senior review of the current change |
| `/lfg:secure` | Dependency, secret and code security checks |
| `/lfg:note <thing to remember>` | Save a decision or lesson |

## In the terminal

| Command | What it does |
| --- | --- |
| `lfg ui` | This dashboard |
| `lfg enable` / `lfg disable` | Turn LFG on or off in the current repo |
| `lfg doctor` | Check that everything works |
| `lfg add <pack>` | Add a feature pack (security, knowledge, dictate…) |
| `lfg hotspots` | Files that keep needing fixes |
| `lfg update` | Is there a newer LFG? |

## Your own docs and knowledge

Add docs on the **Docs** page (*New doc*), and paste notes, decisions and lessons on the **Knowledge** page
(*Add knowledge*). Both are Markdown, saved on this computer, and Claude reads them in this project.
